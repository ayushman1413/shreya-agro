Shreya Agro Foods — On-Page SEO & Website Performance Guidelines
Please follow these SEO and performance guidelines across the complete website.
1. Website Performance — Mandatory
Images
* Use WebP as the default image format.
* Use AVIF where browser compatibility and implementation allow.
* Do NOT upload unnecessarily large JPG/PNG images.
* Compress every image before uploading.
* Product images should generally be kept lightweight while maintaining visual quality.
* Avoid uploading a 2–5 MB image when a compressed 100–300 KB WebP can provide the same visual quality.
* Use responsive images with appropriate sizes for desktop, tablet and mobile.
* Do not load a 1920px/large desktop image on mobile when a smaller version is available.
* Use srcset and responsive image sizing where appropriate.
* Every meaningful image must have descriptive alt text.
* Decorative images should use empty alt attributes where appropriate.
Image naming
Do NOT use:
IMG_1234.jpg
DSC00123.png
product-final-new.jpg
Use descriptive filenames:
shreya-agro-foods-product-name.webp
For example:
shreya-agro-foods-biscuits.webp
________________


2. Lazy Loading
* Images below the first screen should use lazy loading.
* Do NOT lazy-load the main hero/LCP image.
* Hero images should be optimized and loaded immediately.
* Product listing images should lazy-load as they enter the viewport.
* Avoid loading all product images at initial page load.
Example:
loading="lazy"
Use appropriate width and height attributes to prevent layout shifting.
________________


3. Core Web Vitals
Target a fast website and good Core Web Vitals.
Focus especially on:
LCP
Target: ≤ 2.5 seconds
INP
Target: ≤ 200 ms
CLS
Target: ≤ 0.1
Developer should test the website using:
* Google PageSpeed Insights
* Google Search Console
* Lighthouse
* Chrome DevTools
Do not sacrifice page speed for unnecessary animations, sliders or heavy JavaScript.
________________


4. Mobile First
The website must be properly optimized for:
* Mobile
* Tablet
* Desktop
Google primarily evaluates the mobile version of websites, so mobile performance and content must not be treated as secondary.
Make sure:
* No horizontal scrolling
* Buttons are easy to tap
* Text is readable without zooming
* Forms work properly on mobile
* Product images load correctly
* Navigation is fast
* Sticky chatbot does not cover important buttons/content
________________


5. Page URLs
Keep URLs short, readable and SEO-friendly.
Good:
/about-us/
/products/
/products/product-name/
/contact-us/
/careers/
Avoid:
/page?id=123
/products/category/product?id=5678
Use lowercase URLs.
Use hyphens instead of underscores.
________________

Every page must have a unique SEO title.
Recommended format:

Careers
Careers at Shreya Agro Foods | Job Opportunities
Do not duplicate the same title across multiple pages.
________________


7. Meta Description
Every indexable page should have a unique meta description.
Keep it natural and focused on the actual page.
Example:
Shreya Agro Foods is an FMCG company with 26+ years of experience, offering quality food products and B2B business opportunities across India.
Do NOT keyword-stuff meta descriptions.
________________

Each product page should contain:

* Related products

Do not create product pages that contain only an image and product name.

14. Schema / Structured Data
Implement relevant Schema.org structured data.
Recommended:
Organization Schema
For the company.
Include, where applicable:
* Company name
* Website
* Logo
* Contact information
* Social profiles
* Address
Product Schema
For individual product pages.
Include only information that is actually displayed and accurate.
BreadcrumbList Schema
For product/category pages.
WebSite Schema
For the website.
LocalBusiness
Use only if the business/location information qualifies and is accurately represented.
Do NOT add fake ratings, reviews, prices or other structured data.
________________


15. Robots.txt
Create and properly configure:
/robots.txt
Do not accidentally block:
* Important pages
* CSS
* JavaScript
* Images
* Product pages
Admin/private areas should generally not be crawlable.
________________


16. XML Sitemap
Create:
/sitemap.xml
Include all important indexable URLs.
Do not include:
* Admin pages
* Login pages
* Duplicate URLs
* Temporary pages
* Parameter variations
* Thin pages
Submit the sitemap through Google Search Console.
________________


17. Canonical URLs
Every indexable page should have a correct canonical URL.
Example:
https://www.shreyaagrofoods.com/products/product-name/
Avoid duplicate indexing caused by:
* URL parameters
* trailing slash variations
* HTTP vs HTTPS
* www vs non-www
* duplicate category URLs
________________


18. HTTPS
Entire website must use HTTPS.
Redirect:
HTTP → HTTPS
Also maintain one preferred version:
https://www...
or
https://...
Do not allow multiple versions of the same page to remain accessible.
________________

Create a useful custom 404 page.

Buttons:

Explore Products
Contact Us
Return the correct 404 HTTP status code.
________________

Avoid unnecessary:
* Heavy JavaScript libraries
* Large background videos
* Auto-playing high-resolution videos
* Excessive animation
* Unnecessary sliders
* Large third-party scripts
* Multiple font families
* Unused CSS
Use:
* Minified CSS
* Minified JavaScript
* Browser caching
* Compression
* CDN where appropriate
* Code splitting
* Lazy loading
* Optimized fonts
________________

22. Hero Video
If the homepage uses video:
* Compress video heavily.
* Use WebM/MP4 appropriately.
* Provide a lightweight poster image.
* Do not make a huge video the only important content.
* Avoid loading unnecessary video on mobile.
* Consider using a static optimized image on slower mobile connections.
The first visible section must remain fast.
________________


23. Accessibility
Follow basic accessibility practices:
* Proper alt text
* Correct heading hierarchy
* Keyboard-accessible buttons
* Form labels
* Sufficient text contrast
* Visible focus states
* Descriptive button text
Avoid using images containing important text instead of actual HTML text.
________________

Before launch:
1. Verify the domain in Google Search Console.
2. Submit sitemap.xml.
3. Check indexing.
4. Check mobile usability.
5. Check Core Web Vitals.
6. Check Page Experience.
7. Check indexing errors.
8. Check excluded URLs.
9. Test important product pages.
10. Request indexing for important new pages where appropriate.
________________

Do not load multiple unnecessary analytics/tracking scripts.
________________

FMCG company in Malad
FMCG company in Kandivali
unless there is genuinely relevant content/business presence there.
